# Contributing to sinty-accounts

Thanks for your interest in contributing!

## Quick Start

```bash
git clone https://github.com/singularityos-lab/sinty-accounts
cd sinty-accounts
go build ./...
go test ./...
```

## Guidelines

- Keep changes additive and tested. sinty-accounts runs as root and edits the user database;
  prefer small, verifiable commits over large rewrites.
- Match the surrounding style. Comments explain WHY, not WHAT.
- By submitting a contribution you agree to the [CLA](CLA.md).
